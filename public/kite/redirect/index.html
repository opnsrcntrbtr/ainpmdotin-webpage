Kite login callback

Zerodha sends you here after a Kite Connect login. This page reads the request token from the URL and shows it — nothing is stored, logged or transmitted anywhere.

Reading callback…

request_token

Single-use and valid for a few minutes. Exchange it for an access token from your own machine.

Next steps, locally

  1. Paste the token into your script or .env as KITE_REQUEST_TOKEN.
  2. POST api_key, request_token and the SHA-256 checksum of api_key + request_token + api_secret to /session/token.
  3. Keep the returned access_token on disk locally. It expires around 06:00 IST the next day.
Why this page does nothing else. It is served by GitHub Pages to anyone who visits, so it never touches api_secret and never performs the token exchange. A leaked request token is useless on its own and expires; a leaked API secret is not and does not.
